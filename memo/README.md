# 备忘录（MVP）

一个本地优先的 Windows 桌面备忘录原型：默认停靠在右上角，半透明、始终置顶。它是未来“总管”协调系统中的一个部门，而不是总管本身。

## 现在能做什么

- 事件队列优先显示；右下角的 `+` 打开添加事件面板。
- 输入 `明天下午 3 点和张总开会，准备报价单`，由“备忘与事件部”提取事件、时间和优先级；也可在添加面板手动选择类别、开始时间与截止时间，手动截止时间优先。
- 本地解析中英文混合写法，无需 API 或联网：例如 `5339 quizz 10.25` 会记为课程 5339 的学习事项、10 月 25 日全天截止；`下周五 5339 quiz at 3pm` 会记为下周五 15:00。支持 `明天 / 后天 / 下周五 / next Friday / Oct 25`，以及 `important / urgent / 重要 / 紧急` 等优先级词。没有写具体时刻的日期会保存为“全天截止”，不会擅自补充时分。
- 使用队列左侧的 Filter 按类别查看，并可按开始或截止时间排序；完成或删除事件。
- 默认勾选完成后，事件会立即从主页队列隐藏；可在设置中改成保留到当天结束或保留 24 小时。所有完成项仍会保留在事件台账，且可恢复为待办。
- 对只有开始时间但已过开始时间的事件、以及 12 / 6 小时内截止的事件显示 `！` 警示。
- 设置页提供 Jira 风格的完成概览、类别条形图、近七日折线点图与可横向滚动的事件台账；CSV 导出采用同一套台账字段，JSON 则保留完整活动历史和回收站。
- 删除事件会移入回收站，可恢复或永久清除；永久清除后无法恢复。
- 本地保存数据；不连接外部账户，不会把内容发送到网络。
- 右侧有一个可手动收纳的快捷功能抽屉：窄玻璃标签上的三个箭头会依次脉冲；收起时光波从左至右，展开后从右至左。按钮从箭头右侧展开，箭头和展开条由同一个连续玻璃背景层绘制，并保持同一高度。点箭头展开或收起图钉、交互锁、设置和添加。图钉只固定窗口位置与尺寸（📌 固定 / 📍 可移动）；交互锁只控制点击穿透（🔓 可交互 / 🔒 穿透底层），两者互不影响。点击穿透时，添加、设置和图钉均不可操作，只有交互锁本身仍可点击以恢复交互；`Ctrl + Alt + L` 也可作为备用方式。所有本地写入会串行保存，避免创建事件与设置操作并发时互相覆盖。设置中可分别调节背景透明度、内容透明度、窗口固定和始终置顶；取消固定后仍可选择保持置顶。
- 右上角显示苹果玻璃质感的数字时钟；`×` 会关闭到后台。

## 运行

需要 Node.js 20+。在本项目目录打开 PowerShell：

```powershell
npm install
npm start
```

首次运行或换电脑时，先执行一次 `npm install`；之后只需 `npm start`。首次启动会自动在桌面创建或更新 `Memo` 图标，以后双击它即可运行。

## 数据位置

正式版本会把事件数据、保存位置配置与运行缓存统一存放在项目内的 `data/` 文件夹：`memo/data/steward-memo.json`。该文件夹只包含本机私人数据；Git 忽略规则、发布白名单与自动隐私校验都会排除它，因此不会上传到 GitHub 或进入发布包。

## 开关与关闭

- **显示 / 隐藏：** 按 `Ctrl + Alt + M`。右上角的 `×` 也会隐藏窗口，而不是退出程序。
- **锁定窗口：** 点击右下角的 `🔒`；锁上时会同时锁定窗口位置与尺寸，解锁后才能移动或缩放。
- **移动与缩放窗口：** 解锁后，可拖动顶部标题区域移动窗口；任一边和四个角都有加宽的缩放热区，可拖动缩放。最小尺寸为 220 × 160。
- **调整透明度与主题：** 点击右下角 `⚙`，可分别把“背景透明度”调到 0（完全透明）或调低“内容透明度”。按住透明度滑杆时设置页会退下，以主页预览调整效果；设置页本身保持清晰。可用“主题颜色”色盘自选主色。
- **添加事件：** 点击右下角 `＋`；在输入框中输入后可选开始时间和截止时间，再点击“添加”。
- **开机启动与保存位置：** 启动 Memo 时会自动创建或更新桌面图标。打开 `⚙` 可启用“开机自动运行”，并查看或更改数据保存文件夹。更改位置时，当前事件数据会复制到新文件夹；若新文件夹已存在同名数据文件，为避免覆盖不会切换。
- **彻底退出：** 打开 `⚙`，点击“退出备忘录”。
- **事件记录与导出：** 设置页的“事件台账”按工作、类别、优先级、状态、创建/更新时间、截止日期呈现，并可直接删除（移入回收站）；CSV 会导出同一张台账（含已删除状态），JSON 则保留完整活动历史与回收站。Update history 可点右侧三角折叠。

## 总管接口

Memo 是总管的第一个可连接部门。它在 `steward.department.json` 中公开一个版本化的清单，并且只通过 Windows 本地命名管道处理 JSON Lines 请求；它不开放网络端口。

当前仅公开两项已授权能力：

- `capture`：将一段自然语言记录成事件；
- `list`：返回用于总管概览的有限事件字段，不返回完整 Memo 数据文件。

内部仍使用统一的 `manifest + action + result` 合同：`src/departments/memo-events/index.js` 负责事件解析，`src/transport/local-bridge.js` 负责本地传输。未来日历、消息或文件部门可用相同清单和动作模型接入，但必须先在总管登记册中明确登记、审核权限并批准可调用动作；外部软件不会因存在于某个文件夹中而自动获得访问权。
